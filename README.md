## 🌟 Major Highlights

### 🧩 DevApp — Drag & Drop Flutter App Builder
<a href="https://github.com/ritheshSalyan/DevApp-DragPlatform">
  <img align="right" width="400" src="https://github-readme-stats.vercel.app/api/pin/?username=ritheshSalyan&repo=DevApp-DragPlatform&theme=tokyonight&hide_border=true" />
</a>

A **FlutterFlow-style visual builder** written in Flutter itself.

- 🖱️ Drag and drop widgets onto a canvas to design screens visually
- ⚙️ Edit properties and layout live, with instant preview
- 🧬 **Generates real Flutter/Dart code** from the visual design
- ☁️ Firebase-backed (Firestore, Storage, Hosting) and runs on the web

<br clear="right"/>

### 🎮 Slide Z — 3D + AR Sliding Puzzle
<a href="https://github.com/ritheshSalyan/flutter_sliding_puzzle">
  <img align="right" width="400" src="https://github-readme-stats.vercel.app/api/pin/?username=ritheshSalyan&repo=flutter_sliding_puzzle&theme=tokyonight&hide_border=true" />
</a>

Built for the **Flutter Puzzle Hack** challenge — and **featured in a video** 🎥.
A sliding puzzle where tiles become **3D pillars of different heights**, sorted by height.

- 🧊 **3D engine from plain widgets** — cubes made of transformed widget faces, with depth-sorted draw order
- 🥽 **AR mode** — Mind AR in a WebView drives transforms, so *any Flutter widget* can be placed in AR
- 🟫 **Voxel support** — custom `.vox` (MagicaVoxel) parser with **greedy meshing** for performance
- 🎛️ Gyro, touch, mouse and keyboard controls · runs on mobile, web and desktop
